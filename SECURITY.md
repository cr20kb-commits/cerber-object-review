# Security and privacy / Безопасность

Не публикуйте ключи, пароли, персональные данные и материалы дел в Issues или PR.
Локальный валидатор не является фильтром личных данных.

Для уязвимости кода используйте вкладку GitHub **Security → Report a vulnerability**,
если приватные сообщения включены. Если кнопки нет, не размещайте чувствительный
пример публично: воспользуйтесь GitHub Support для утечек на платформе.
Для срочной ротации утёкшего ключа обращайтесь к провайдеру ключа.
Сведения для следствия — через официальную карточку Europol после проверки человеком.

Do not disclose secrets, personal data or case materials in public. For code vulnerabilities,
use GitHub Security → Report a vulnerability if enabled. If unavailable, do not post a
sensitive reproduction publicly; contact GitHub Support about platform data exposure.
Revoke exposed credentials through their provider. Investigative leads belong in the
official Europol card form after human review, not this repository.
